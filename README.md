## What this is

Exactly what the description says: a throwaway repo for checking how [GitHub Pages](https://pages.github.com) serves a site. It contains a single `index.md`, which Pages renders to HTML through its built-in Jekyll processing.

Kept because it's occasionally useful to have a known-good minimal Pages repo to test against. Not a project, and nothing here is intended for reuse.
